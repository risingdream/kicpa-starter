## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
나는 회계사로서 매입 증빙 장부에서 거래처마다 몇 건이고 공급가액과 부가세를 얼마나 썼는지 한눈에 보고 싶다. 끝나면 가상 증빙 3건(가상 문구점 120,000원·38,000원, 가상 인쇄소 450,000원)으로 장부 아래 거래처별 합계 표(거래처 / 건수 / 공급가액 합계 / 부가세 합계, 맨 아래 전체 합계 행)가 손계산과 같은지로 확인한다.

1일차 하루 예제다. 5.1 와이어프레임(3강) → 5.2 화면에서 더하는 표(3강) → 5.3 합계 계산을 서버로 옮기기(4강) → 5.4 QA(5강) 순서로 한 장부를 이어서 고친다. 이슈마다 끝난 상태는 브랜치 v2/d1-design-done(5.1), v2/d1-ui-done(5.2), v2/d1-done(5.3)에, QA 연습판은 v2/d1-qa-bug에 있다(docs/checkpoints.md).

하지 말 것: 기간·월별 합계(2일차 TASK-3), 거래처 편집·삭제, 그래프, 증빙 3건 밖의 실제 자료
