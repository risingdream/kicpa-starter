# 거래처별 합계 표를 화면에 만든다

1일차 3강. 이슈 1에서 사람이 확인한 와이어프레임대로 화면을 만든다.

1. `stack/web`에 디자인시스템(Tailwind CSS와 shadcn/ui)을 깐다. 다 깔면 `AGENTS.md`에 새 화면은 그 부품과 색만 쓴다는 규칙을 적는다.
2. 장부 목록 아래에 거래처별 합계 표(거래처 / 건수 / 공급가액 합계 / 부가세 합계, 맨 아래 전체 합계 행)를 붙인다. 합계는 지금 있는 증빙 목록 API(`GET /api/receipts`)로 화면에서 더한다. 서버로 옮기는 일은 이슈 3에서 한다.
3. 스모크 테스트(기능이 기본으로 도는지 짧게 보는 확인): 브라우저로 화면을 열어 표가 뜨고 숫자가 와이어프레임과 같은지 본다.

Tailwind CSS·shadcn/ui가 쓰는 패키지는 `stack/web/package.json`에 미리 넣어 두었다(설정과 부품은 아직 없다). 강의 시간 안에 끝나지 않으면 완성본 브랜치 `v2/d1-ui-done`으로 바꾼다(`docs/checkpoints.md`).

## 하지 말 것

- 서버(`stack/api`)·DB(`stack/db`) 수정
- 와이어프레임에 없는 화면 추가

## 인수 조건

- [ ] 화면의 거래처별 합계 표가 가상 증빙 3건에서 가상 문구점 2건·158,000원·15,800원, 가상 인쇄소 1건·450,000원·45,000원, 전체 3건·608,000원·60,800원이다
- [ ] 증빙이 없으면 거래처별 합계 자리에 '표시할 거래가 없습니다'가 보인다
- [ ] 표가 shadcn/ui 표 부품과 Tailwind 테마 색으로 그려지고, `AGENTS.md`에 새 화면은 그 부품과 색만 쓴다는 규칙이 있다
