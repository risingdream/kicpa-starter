## 1. 무엇을 만드는가

| 항목 | 내용 |
|---|---|
| 스토리 한 줄 | 나는 ___로서 ___를 원한다. 끝나면 ___로 확인한다 |
| 이번에 코드로 만들 결정 구간 하나 | 예) 매입 파일의 열 이름과 합계가 맞는지 검사한다 |
| 사람이 계속 맡을 부분 | 예) 불일치 원인 판단, 거래처 문의 |
| 사람이 확인할 경계 | 예) 결과 목록을 보고 반영 여부는 사람이 정한다 |
| 가장 작은 결과물 | 예) 파일 하나를 넣으면 불일치 목록이 나오는 화면 한 장 |
| 하지 말 것 | 예) 신고 제출, 전표 반영, 실제 고객 자료 |
