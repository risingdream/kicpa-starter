# 화면 기획 — 매입 증빙 (거래처별 합계 추가)

- 목적: 증빙을 넣고, 거래처마다 공급가액과 부가세가 얼마인지 한눈에 본다.
- 가장 먼저 보일 것: 증빙 목록과 그 아래 거래처별 합계 표
- 끝나면: [추가]로 저장하면 증빙 목록과 거래처별 합계가 함께 새로 고쳐진다. 저장이 안 되면 입력 칸 아래에 빨간 글씨로 이유가 나온다.

## 화면

`stack/` 매입 증빙 화면(<http://localhost:5173>). 예시 숫자는 처음 띄운 DB의 가상 증빙 3건이다.

```text
+-----------------------------------------------------------+
| 매입 증빙                                                  |
| 교육용 가상 자료입니다. 실제 거래처를 넣지 마세요.         |
+-----------------------------------------------------------+
| 날짜 [2026-10-27]  거래처 [가상 거래처]  공급가액 [      ] |
| [ 추가 ]  → 아래 두 표가 새로 고쳐진다                     |
+-----------------------------------------------------------+
| 증빙 목록                                                  |
| +------------+-------------+-------------+-----------+    |
| | 날짜       | 거래처      |    공급가액 |    부가세 |    |
| +------------+-------------+-------------+-----------+    |
| | 2026-10-01 | 가상 문구점 |   120,000원 |  12,000원 |    |
| | 2026-10-07 | 가상 인쇄소 |   450,000원 |  45,000원 |    |
| | 2026-10-15 | 가상 문구점 |    38,000원 |   3,800원 |    |
| +------------+-------------+-------------+-----------+    |
| | 합계                     |   608,000원 |  60,800원 |    |
| +------------+-------------+-------------+-----------+    |
+-----------------------------------------------------------+
| 거래처별 합계                                              |
| +-------------+---------------+-------------+             |
| | 거래처      | 공급가액 합계 | 부가세 합계 |             |
| +-------------+---------------+-------------+             |
| | 가상 문구점 |     158,000원 |    15,800원 |             |
| | 가상 인쇄소 |     450,000원 |    45,000원 |             |
| +-------------+---------------+-------------+             |
+-----------------------------------------------------------+
```

- 거래처별 합계는 지금 있는 증빙 목록(`GET /api/receipts`)을 화면에서 거래처 이름으로 묶어 더한다. 서버·DB는 바꾸지 않는다.
- 부가세 합계는 증빙마다 계산된 부가세를 더한 값이다(공급가액 합계에 10%를 다시 곱하지 않는다). 그래야 증빙 목록의 부가세와 맞는다.
- 거래처 순서는 이름 가나다순이다.
- 공급가액이 마이너스인 증빙(반품·에누리)도 그대로 더한다. 합계가 마이너스면 `-12,000원`처럼 보인다.
- 거래처 이름은 글자 그대로 비교한다(앞뒤 공백·띄어쓰기가 다르면 다른 거래처).

## 상태

| 상태 | 어떻게 보이나 |
|---|---|
| 정상 | 증빙 목록 표, 그 아래 거래처별 합계 표(거래처마다 한 줄) |
| 빈 상태 | 증빙이 한 건도 없으면 두 표 자리에 각각 "표시할 거래가 없습니다" 한 줄 |
| 로딩 | "불러오는 중입니다…" |
| 오류 | 빨간 글씨로 이유 한 줄. 예) "목록을 가져오지 못했습니다: 서버 응답 500" |

빈 상태:

```text
+-----------------------------------------------------------+
| 증빙 목록                                                  |
|   표시할 거래가 없습니다                                   |
+-----------------------------------------------------------+
| 거래처별 합계                                              |
|   표시할 거래가 없습니다                                   |
+-----------------------------------------------------------+
```
