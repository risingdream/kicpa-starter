# 화면 기획 — (화면 이름)

- 목적: (이 화면에 온 사람은 무엇을 하러 왔는가, 한 문장)
- 가장 먼저 보일 것: (하나만)
- 끝나면: (저장 뒤 어디로, 잘못되면 어디로)

## 화면

예시: 이 저장소에 들어 있는 부가세 계산 화면

```text
+-----------------------------------------+
| 부가세 계산                              |
| 실습용 예시 화면입니다 ...               |
+-----------------------------------------+
| 공급가액 (원)                            |
| [ 예) 100,000            ]               |
| [ 계산하기 ]  → 아래 결과 칸             |
+-----------------------------------------+
| 결과                                     |
|  공급가액: 100,000원                     |
|  부가세:    10,000원                     |
|  합계:     110,000원                     |
+-----------------------------------------+
```

## 상태

| 상태 | 어떻게 보이나 |
|---|---|
| 정상 | 공급가액·부가세·합계 세 줄 |
| 빈 상태 | "공급가액을 넣고 [계산하기]를 누르면 여기에 결과가 나옵니다." |
| 로딩 | "계산하는 중입니다…" |
| 오류 | 빨간 글씨로 이유 한 줄. 예) "공급가액은 0 이상의 정수(원)로 입력해 주세요." |
