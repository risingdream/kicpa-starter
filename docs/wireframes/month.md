# 화면 기획 — 달을 골라 그 달 증빙만 보기

- 목적: 매달 마감할 때 그 달의 매입 증빙과 합계만 본다.
- 가장 먼저 보일 것: 장부 위의 월 선택 칸
- 끝나면: 고른 달의 목록과 합계가 바로 바뀐다. 잘못되면 빨간 글씨로 이유 한 줄

## 화면

```text
+--------------------------------------------------+
| 매입 증빙                                         |
| [날짜] [거래처] [공급가액] [추가]                 |
+--------------------------------------------------+
| 월 [ 2026-10 ▼ ]  [ 전체 보기 ]                   |
+--------------------------------------------------+
| 날짜       | 거래처      |   공급가액 |   부가세 |
| 2026-10-01 | 가상 문구점 |  120,000원 | 12,000원 |
| 2026-10-07 | 가상 인쇄소 |  450,000원 | 45,000원 |
| 2026-10-15 | 가상 문구점 |   38,000원 |  3,800원 |
| 합계                     |  608,000원 | 60,800원 |
+--------------------------------------------------+
```

## 상태

| 상태 | 어떻게 보이나 |
|---|---|
| 정상 | 고른 달의 증빙과 그 달 합계 |
| 빈 상태 | 표 대신 "이 달 증빙이 없습니다" |
| 로딩 | 바꾸기 전 목록을 그대로 둔다 |
| 오류 | 빨간 글씨로 "목록을 가져오지 못했습니다: …" |

## API 약속

- 요청: `GET /api/receipts?month=YYYY-MM`. `month`가 없으면 지금처럼 전체를 돌려준다.
- 응답: 지금과 같은 모양 `{ items, total_supply, total_vat }`. 새 필드를 더하지 않는다. `items`와 합계는 그 달 증빙만 담는다.
- 오류: `month` 형식이 틀리면(예: `2026-13`, `202610`) 422.
- 증빙 추가(`POST /api/receipts`)는 바꾸지 않는다. 화면은 추가한 뒤 지금 고른 달로 다시 부른다.
