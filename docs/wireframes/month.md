# 화면 기획 — 달을 골라 그 달 증빙만 보기

- 목적: 매달 마감할 때 그 달의 매입 증빙과 거래처별 합계만 본다.
- 가장 먼저 보일 것: 증빙 목록 위의 월 선택 칸
- 끝나면: 달을 고르면 증빙 목록과 거래처별 합계가 함께 그 달 것으로 바뀐다. 잘못되면 빨간 글씨로 이유 한 줄

## 화면

예시 숫자는 처음 띄운 DB의 가상 증빙 4건(10월 3건, 11월 1건)에서 2026-10을 고른 모습이다.

```text
+---------------------------------------------------------------+
| 매입 증빙                                                      |
| 날짜 [2026-10-20]  거래처 [가상 거래처]  공급가액 [        ]   |
| [ 추가 ]  → 지금 고른 달로 두 표가 새로 고쳐진다               |
+---------------------------------------------------------------+
| 월 [ 2026-10 ]  [ 전체 보기 ]  → month 없이 다시 부른다        |
+---------------------------------------------------------------+
| 증빙 목록                                                      |
| | 날짜       | 거래처      |    공급가액 |    부가세 |          |
| | 2026-10-01 | 가상 문구점 |   120,000원 |  12,000원 |          |
| | 2026-10-07 | 가상 인쇄소 |   450,000원 |  45,000원 |          |
| | 2026-10-15 | 가상 문구점 |    38,000원 |   3,800원 |          |
| | 합계                     |   608,000원 |  60,800원 |          |
+---------------------------------------------------------------+
| 거래처별 합계                                                  |
| | 거래처      | 건수 | 공급가액 합계 | 부가세 합계 |            |
| | 가상 문구점 |  2건 |     158,000원 |    15,800원 |            |
| | 가상 인쇄소 |  1건 |     450,000원 |    45,000원 |            |
| | 전체        |  3건 |     608,000원 |    60,800원 |            |
+---------------------------------------------------------------+
```

## 상태

| 상태 | 어떻게 보이나 |
|---|---|
| 전체(처음 열 때) | 월 칸이 비어 있고 모든 증빙. 4건 / 628,000원 / 62,800원 |
| 정상(달을 고름) | 그 달 증빙과 그 달 거래처별 합계. 2026-10이면 3건 / 608,000원 / 60,800원, 2026-11이면 1건 / 20,000원 / 2,000원 |
| 빈 달 | 두 표 자리에 각각 "이 달 증빙이 없습니다" 한 줄(예: 2026-12) |
| 증빙이 하나도 없음(전체) | 1일차와 같이 "표시할 거래가 없습니다" |
| 로딩 | 바꾸기 전 표를 그대로 둔다 |
| 오류 | 빨간 글씨로 "목록을 가져오지 못했습니다: …" |

## API 약속

- 요청: `GET /api/receipts?month=YYYY-MM`, `GET /api/receipts/by-vendor?month=YYYY-MM`. 둘 다 `month`가 없으면 지금처럼 전체를 돌려준다.
- 범위: `month`가 있으면 그 달 1일 이상 ~ 다음 달 1일 미만의 증빙만 담는다(`2026-12`면 2026-12-01 이상 2027-01-01 미만).
- 응답: `month`가 없을 때와 같은 모양이다. 새 필드를 더하지 않는다.
  - 목록: `{ items, total_supply, total_vat }`
  - 거래처별 합계: `{ items: [{ vendor, count, supply, vat }], total: { count, supply, vat } }`
  - 그 달 증빙이 없으면 `items`는 빈 목록, 합계는 0이고 상태 코드는 200이다.
- 오류: `month` 형식이 틀리면(예: `2026-13`, `202610`) 422.
- 증빙 추가(`POST /api/receipts`)는 바꾸지 않는다. 화면은 추가한 뒤 지금 고른 달로 두 주소를 다시 부른다.
